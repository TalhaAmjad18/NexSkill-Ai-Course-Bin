# 📈 Final Assessment — Stock Market Prediction

One of the major components of this repository is the **Stock Exchange Prediction Final Assessment**.

The assessment explores predictive modeling using historical stock-market datasets from multiple companies:

|   Company  |      Dataset     |  Implementation |
| :--------: | :--------------: | :-------------: |
|    Adobe   |    `Adobe.csv`   |    `Adobe.py`   |
|  Microsoft |  `Microsoft.csv` |  `Microsoft.py` |
| Salesforce | `Salesforce.csv` | `Salesforce.py` |
|   Oracle   |   `oracle.csv`   |   `oracle.py`   |

The repository also includes a **Stock Exchange Prediction Final Report** documenting the assessment.

### Key Concepts

* Historical financial data analysis
* Data preprocessing
* Feature engineering
* Exploratory analysis
* Predictive modeling
* Model evaluation
* Comparing machine learning approaches
* Interpreting prediction performance

> **Note:** The stock-prediction work is an educational machine-learning exercise and should not be interpreted as financial advice or a trading recommendation.
